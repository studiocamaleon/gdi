# Componentes de terceros

El editor y las recetas geométricas de Forma Studio se implementaron para este proyecto. No incluyen código, marca, vídeos ni recursos de LetraMaker.

Las dependencias instaladas conservan sus avisos en los paquetes originales. Los avisos directos se incluyen también en `public/licenses/`, junto al compilado:

| Dependencia | Licencia declarada |
|---|---|
| React, React DOM, Three.js, Vite, Tailwind CSS | MIT |
| Manifold, class-variance-authority | Apache-2.0 |
| OpenType.js | MIT |
| Base UI y componentes shadcn | MIT |
| jsPDF, fflate, maxrects-packer, Zod, Sonner | MIT |
| Lucide | ISC |
| clsx, tailwind-merge, tw-animate-css | MIT |

Las 16 tipografías se descargaron del repositorio público de Google Fonts. `public/fonts/manifest.json` registra fuente y licencia de cada archivo. Se incluyen los avisos OFL de las familias y la licencia Apache de Permanent Marker. Las fuentes se distribuyen sin modificaciones y no se venden de manera independiente.
